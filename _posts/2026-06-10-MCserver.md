最近想试一试 MC 开服怎么做，这次就在我的 archlinux 的工作站上面试一试。

## 关于 Java

我并没有学过 java 语言。MC 不同版本经常需要不同的 java 版本，这往往很麻烦。但 archlinux 有一个非常优雅的 java 版本管理，参考[官方 wiki 页面](https://wiki.archlinux.org/title/Java) 。

关键在于这句话：

> Arch Linux officially supports the open source OpenJDK versions 8, 11, 17, 21, and 25 — Long-Term Support (LTS) versions. **All these JVMs can be installed without conflict and switched between using helper script archlinux-java (installed with java-runtime-common package)**. Several other Java environments are available in Arch User Repository but are not officially supported.

通过下面的命令不同版本的 OpenJDK

```bash
sudo pacman -S jdk-openjdk
```

具体细节看[第 1.1 节](https://wiki.archlinux.org/title/Java#OpenJDK)。

通过下面的命令下载 archlinux-java 脚本工具

```bash
sudo pacman -S java-runtime-common
```

该工具也会在你使用 pacman 下载任何 java 的时候被自动拉取。
具体如何使用则具体在第二节 [Switching between JVM](https://wiki.archlinux.org/title/Java#Switching_between_JVM)。

### 开服姿势

Step0: 确认设备配置合适，确认 Java 装好，确认建立好了新的目录(`mkdir`)。

Step1: 下载服务器文件，你可以将其重命名为 `server.jar` ，我们后面就称这个文件是 `server.jar`

可以去官方网站 https://www.minecraft.net/en-us/download/server 下载最新版的服务器文件，这个网站里面右键 `minecraft serverxxxxxx` 的超链接即可下载到服务器文件，如果服务器没有 GUI 则复制链接地址然后 wget 即可。

Step2: 运行服务器文件，生成并修改配置文件。

运行下面的命令，这条命令一定会失败，这是用来生成一些配置文件的。

```bash
java -jar server.jar nogui
```

运行后会产生一些其它文件，重点关注两个：
- `eula.txt`: 要进入这个文件把里面的 `false` 改为 `true`，这其实就是所谓的 “用户条款”，考虑到没有 GUI，Mojang 就用这种方式来让你确认 “用户条款” 。
- `server.properties`: 这是一个文本文件，里面有很多服务器的配置开关。下面说一些重要的
  - `difficulty`: 即游戏难度，默认是 `easy`，想玩生电的话就要改为 `hard`
  - `level-name`: 服务器存档，默认是· `world`，启动前可以通过该这个来切换存档
  - `server-port`: 开放端口，默认是 `25565`
  - `online-mode`: 是否开启正版验证，默认是 `true`
  - `white-list`: 是开白名单模式，默认是 `false`，开了之后只有白名单列表的玩家才允许加入
  - `max-tick-time`: 卡顿看门狗，如果服务卡顿超过设定时间，则强制关闭服务器。默认是 `60000`（一分钟），这个建议调高一点。
  - `pause-when-empty-seconds`: 服务器空闲（没玩家上号）一段时间后，服务器会自动暂停以节能，默认是 `60`，设为 `-1` 以永不暂停。

其实运行方法，在官方的服务器文件下载页面里面其实就说了，就在下载链接的正下方，有一行命令，我们来看看这个命令是什么意思。

```bash
java -Xmx1024M -Xms1024M -jar minecraft_server.1.21.11.jar nogui
```

- 感觉 `-jar` 是核心参数，告诉 java 运行一个 JAR 包，也就是刚刚下载下来的服务器文件。
- `minecraft_server.1.21.11.jar` 则是服务器文件，这应该是默认下载产生的文件的名字。
- `-Xms1024M` 指的是初始内存，即程序启动时申请的内存大小。如果不输入该参数，默认大概为总内存的 1/64。
- `-Xmx1024M` 指的是最大内存，即运行过程中允许占用的最大内存。如果不输入该参数，默认大概为总内存的 1/4。
- `nogui` 指的是不开 GUI，很多服务器不需要 GUI。

显然官方指定的内存大小基本上是不够畅玩的。。。

### 开服的正确姿势

上面说了开服的流程，但是有一些东西需要注意。

#### 我不想开最新版的服务器

Mojang 官方只提供最新版本服务器文件的下载地址。想要下载其它版本的纯原版服务器文件，有几个办法
- 从第三方网站 https://mcversions.net 下载
- 从官方启动器下载，打开官方启动器，点进 “配置” 选项卡，选择 “新配置”，然后里面有一个小小的下载服务器的地址链接。如下图所示

![]({{ '/assets/imgs/screenshot-2026-01-23-023211.png' | relative_url }})

#### 服务端要后台运行！

上一小节我说用 `java -jar server.jar` 这个命令即可开服。这当然没错。可是服务器是要长期运行的。你运行了这个命令后，如果关闭所处的 terminal ，命令作为 terminal 的子进程当然会被关闭，服务器也被关闭了。

推荐使用终端复用器 `tmux`，archlinux 上面可以直接使用 `pacman` 下载。省流用法如下：

运行 

```bash
tmux new -s mc
```

来开启一个新“会话”，屏幕底部会多一个绿色的状态来标志成功进入会话。

在这个会话栏里面启动服务器，运行 `java -jar server.jar` 或者你编写的替代脚本。

按下 `Ctrl` + `b` ，然后按下 `d` 离开会话，屏幕上会显式一个 `[detached]`，意味着会话已经后台运行。此时关闭所处的终端也不会导致服务器被关闭。

运行

```bash
tmux attach -t mc
```

回到会话中，你可以在此操作服务器。

运行 `exit` 可以退出当前会话。其它 `tmux` 操作请自行查找。
